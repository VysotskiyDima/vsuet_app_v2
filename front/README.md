# Фронтенд · Рейтинг успеваемости ВГУИТ

Статический клиент без сборки и зависимостей (HTML + CSS + ванильный JS). Открывает рейтинг
успеваемости студента по номеру зачётной книжки, обращаясь к локальному бэкенду.

## Запуск

Бэкенд должен быть поднят на `http://localhost:8000` (CORS для localhost уже включён).

Любой статический сервер из папки `front/`:

```bash
cd front
python -m http.server 5500
# открыть http://localhost:5500
```

Для примера используйте зачётку **247162**.

## Структура

- `index.html` — разметка двух экранов: вход (обложка зачётки) и страница рейтинга.
- `styles.css` — оформление (дизайн-токены в `:root`).
- `app.js` — логика: проверка зачётки, параллельная загрузка 8 ведомостей, отрисовка таблиц.

## Настройки

- Адрес API — константа `API_BASE` в начале `app.js`.
- Список типов ведомостей и порядок секций — массив `VED_TYPES` там же.

## Поведение

- Вход: `GET /students/{zach}/exists` → при `exists:true` открывается страница рейтинга.
- Рейтинг: параллельно запрашиваются все типы `GET /rating/{zach}/{segment}`.
  - Секции с пустым ответом `[]` не отображаются.
  - Вид таблицы выбирается по форме записи: есть `control_points` → рейтинговая
    (с контрольными точками), есть `grade` → оценочная.
  - Число контрольных точек динамическое (в данных встречается до 5).
  - Частичные сбои не ломают страницу: показывается, что загрузилось, плюс баннер с «Повторить».

## Дизайн

Идентичность — официальный документ (зачётная книжка): тёплая «бумага», ультрамариновая
печать-подпись, моноширинные «измерительные» таблицы. Шрифты (Google Fonts): Unbounded
(дисплей), Golos Text (текст), JetBrains Mono (данные). Доступность: видимый фокус с
клавиатуры, адаптив до мобильных, учитывается `prefers-reduced-motion`.
